# ⚡ NAZO RUSH — 謎解きA1Z26 フラッシュ暗算トレーナー

謎解きで頻出する「アルファベット順変換（`1 = A` 〜 `26 = Z`）」を、スマホの親指1本で反射的に引き出せるように鍛えるフラッシュ暗算＆スコアアタックゲームです。

👉 **Play Now:** [https://hirafish.github.io/](https://hirafish.github.io/)

## 🎮 主な機能
- **🔥 30秒 / 60秒 スコアアタック & エンドレス練習**
  - 即答（`⚡ GOD SPEED`）や5コンボごとに残り時間が延長されるハイスピード・スコアアタック。
  - 10コンボ達成で **FEVER OVERDRIVE** 突入（スコア倍率 `x2` → `x4` → `x8`）。
- **🎯 謎解き特化の出題モード**
  - `14 → N`（数字→英字）、`N → 14`（英字→数字）、`E + J = O`（アルファベット足し算）。
  - 鬼門の中盤（`11〜19`）絞り込みや、ミス・遅延文字を自動抽出する「苦手特訓」に対応。
- **🧮 フラッシュ単語デコード**
  - 連続でフラッシュする数字列（例：`19 → 20 → 1 → 18`）を頭の中で英単語（`STAR`）に変換。
- **📖 EJOTY 基準点＆語呂合わせ暗記表**
  - `5=E, 10=J, 15=O, 20=T, 25=Y` の基準点と定番の覚え方・文字別の最速反応タイムを記録。
- **🚇 オフライン対応（PWA / Service Worker）**
  - 一度ブラウザで開けば、電波のない電車内や地下でもそのままリロード・プレイ可能。
